# 实施计划

- [ ] 1. 建立有界的编辑字号偏好与兼容存储
- [ ] 1.1 定义编辑字号偏好契约
  - 为编辑字号规定安全默认值、最小值、最大值和单步变化规则，并保持既有显示偏好的默认行为不变
  - 只接受支持范围内的整数；布尔值、非整数与越界值不能成为有效偏好
  - 单独更新字号、段落密度或工作区模式时保留其余显示偏好
  - 完成时，有效边界值可构造，非法值稳定失败，默认字号可供旧状态和异常状态回退
  - _Requirements: 1.5, 2.4, 3.4_
  - _Boundary: DisplayPreferences_

- [ ] 1.2 扩展本地 workspace 显示偏好的兼容读写
  - 在现有 schema v1 显示对象中把编辑字号作为可选字段原子保存，不创建第二份配置权威
  - 读取旧状态、缺失字段、损坏字段或越界字段时，只让字号回退安全默认值并记录告警，且不把回退结果写回原文件
  - 保留其他有效显示偏好和此前有效状态的原子写入语义，字号偏好不得进入项目、翻译记忆库或术语表
  - 完成时，字号可跨存储实例往返恢复，旧 workspace 文件继续可读，异常字号不会破坏启动或其他偏好
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 3.4_
  - _Boundary: WorkspaceStateRepository_

- [ ] 1.3 建立字号本地存储的契约测试
  - 覆盖合法字号往返、旧 schema 缺失字段、类型错误、布尔值和越界字段的字段级回退
  - 验证异常字段会告警但不改写原文件，单项字号保存会保留其他偏好，写入失败会保留此前有效文件
  - 比较操作前后的项目和语言资源快照，确认本地显示偏好没有进入项目、翻译记忆库或术语表
  - 完成时，存储测试可重复证明兼容读取、原子保存、失败恢复与本地隔离
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 3.4_
  - _Boundary: Workspace State Tests_

- [ ] 2. 在 Qt 编辑区接入同步字号行为
- [ ] 2.1 应用并保持 source/target 的同步编辑字号
  - 启动窗口时通过现有控制器恢复字号，并在当前 source 与 target 上使用相同的控件字体和文档默认字体
  - 移除 source 高亮内容及 source/target 样式中的固定字号，使内容重载后仍服从当前显示偏好
  - 段落切换、项目切换以及离开后返回编辑状态时都重新遵守当前会话字号
  - 字号应用只影响编辑 source/target，不改变浏览/校对页、段落列表、菜单、设置或其他控件
  - 完成时，两个编辑区在内容刷新和工作区切换后仍同步显示，项目字段与匹配身份完全不变
  - _Requirements: 1.3, 1.6, 2.2, 3.1, 3.2_
  - _Boundary: QtEditorWindow Font Application_

- [ ] 2.2 过滤编辑 viewport 的 Ctrl+滚轮输入
  - 只在 source/target 编辑 viewport 上，把仅有 Ctrl 修饰且垂直滚轮增量非零的事件解释为一个字号步进
  - 按垂直增量的符号同步放大或缩小，并把结果钳制到支持范围
  - 未按 Ctrl、带额外修饰键、仅有横向或零增量的滚轮继续原有行为；编辑区之外的事件不触发字号变化
  - 完成时，两个编辑 viewport 均可驱动相同缩放，边界不越界，默认滚动与范围外输入未被拦截
  - _Requirements: 1.1, 1.2, 1.4, 1.5, 3.3_
  - _Boundary: QtEditorWindow Input Filter_

- [ ] 2.3 集成字号持久化与失败反馈
  - 先让有效的新字号在当前窗口可见，再经现有控制器单项保存，并保留段落密度和工作区模式
  - 只有有效字号发生变化时才保存；到达最小值或最大值后继续滚动不产生冗余持久化
  - 保存失败时显示“字号偏好未保存”类可理解错误，保留当前可见字号且不破坏此前有效状态
  - 完成时，成功缩放可供新窗口恢复，边界滚动无多余写入，失败分支同时保留视觉结果与旧文件
  - _Depends: 1.2, 2.2_
  - _Requirements: 1.1, 1.2, 1.5, 2.1, 2.5, 3.1_
  - _Boundary: QtEditorWindow Persistence Adapter_

- [ ] 3. 验证 Qt 交互与生命周期隔离
- [ ] 3.1 建立真实滚轮事件测试
  - 覆盖 source/target 双向缩放、同步即时显示、最小/最大边界和边界处无重复持久化
  - 覆盖精确 Ctrl 修饰、额外修饰键、垂直非零条件、普通滚动透传和范围外控件
  - 验证 source 高亮刷新后字号不复位，段落列表、浏览/校对页及其他控件字体不变
  - 完成时，offscreen 事件测试可重复证明输入判定、同步显示、默认滚动和 UI 范围隔离
  - _Depends: 2.2, 2.3_
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5, 2.1, 2.5, 3.2, 3.3_
  - _Boundary: Qt Font Zoom Event Tests_

- [ ] 3.2 建立生命周期、失败和项目完整性测试
  - 覆盖段落、项目、编辑/浏览模式切换以及新窗口重建后的字号保持或恢复
  - 覆盖旧状态、异常状态和保存失败，并验证告警、错误反馈、可见字号与此前有效本地状态
  - 比较包含 source、target、raw speaker、confirmed、段落身份、顺序和匹配身份的项目前后快照
  - 验证字号只读写本地 workspace 状态，执行过程没有网络调用且不修改项目或语言资源
  - 完成时，生命周期集成测试可重复证明恢复语义、失败语义、项目完整性和本机处理边界
  - _Depends: 1.3, 2.3_
  - _Requirements: 1.3, 1.6, 2.2, 2.3, 2.4, 2.5, 3.1, 3.2, 3.3, 3.4_
  - _Boundary: Qt Font Zoom Lifecycle Tests_

- [ ] 4. 完成字号缩放回归验收
- [ ] 4.1 运行完整自动化回归与启动烟测
  - 运行 workspace 状态、Qt UI、边界守卫和完整测试套件，确认前端仍只经控制器访问本地状态
  - 运行无头启动烟测，确认窗口可用、已有项目流程不退化且字体偏好不影响无 Qt 错误反馈
  - 完成时，完整自动化回归与 offscreen smoke 均通过，无新增架构边界违规
  - _Depends: 1.3, 3.1, 3.2_
  - _Requirements: 1.6, 2.2, 2.3, 3.1, 3.2, 3.4_
  - _Boundary: Regression Validation_
