# ADR-003：xlwings 导入隔离（单文件、不在运行时查询路径）

- **状态**：已采纳
- **日期**：2026-05-16
- **决策**：xlwings 作为 Layer 4（Frontend）的外部依赖，被隔离在单一文件（excel_adapter.py）中，通过条件导入（conditional import）引入。xlwings 不出现在运行时翻译查询路径上——仅在 Excel 读写操作时激活，不参与 TM/Glossary 匹配逻辑。
- **理由**：xlwings 依赖 Microsoft Excel 运行时（Windows/macOS only），引入平台锁定。将其隔离在单一文件中并排除在运行时查询路径之外，确保核心翻译功能（L1-L3）在无 Excel 环境下正常运行，且 xlwings 导入失败不会导致应用崩溃。
- **约束**：(1) xlwings 相关代码必须集中在 excel_adapter.py，不得扩散到其他文件。(2) 任何涉及 xlwings 的导入必须使用 try/except 包裹，导入失败时降级到 openpyxl 路径或报错。(3) xlwings 绝对不能出现在 TM 查询或 Glossary 匹配的调用链中。
