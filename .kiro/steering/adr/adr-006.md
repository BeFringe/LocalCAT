# ADR-006：TM 采用内存 Dict 精确匹配索引（当前策略，含扩展条件）

- **状态**：已采纳
- **日期**：2026-05-16
- **决策**：TM 查询使用 Python 内置 dict 作为内存中的精确匹配索引——将源文文本作为 key，翻译条目作为 value。此策略为当前阶段的实现选择，附有明确的扩展条件。
- **理由**：Dict 提供 O(1) 精确查找，实现简单，且为 Python stdlib 内置，无需额外依赖。在当前数据规模下（典型 TM 文件数千至数万条目），内存占用和查找性能均表现良好。
- **约束**：(1) 当前策略的有效性边界：TM 条目数量约 ~1M 条以内。超过此阈值时，需重新评估索引策略（如引入磁盘索引、分片、或近似匹配优化）。(2) Dict 索引要求源文可哈希且可完整加载到内存——不支持流式查询。(3) 修改此策略需要同步修改 tm_engine.py 的索引构建和查询接口。
