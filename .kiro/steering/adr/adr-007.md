# ADR-007：SQLite generation 成为 canonical TM，JSONL 保留为配置源与兼容交换面

- **状态**：草案（实现已落地，待治理确认）
- **日期**：2026-08-16
- **背景**：ADR-002 与 ADR-006 将 JSONL append-only/LWW 和内存 dict 精确索引定义为当时的 TM 运行时策略。Feature 5 在保留 JSONL 兼容输入、安全迁移与导出能力的同时，已将版本化记录、context/provenance、候选索引和统一查询转移到 SQLite generation。
- **决策**：
  1. 已激活的 SQLite generation 是 TM 精确、context、fuzzy 查询及本地追加的 canonical runtime authority。
  2. 配置仍指向用户 JSONL；JSONL 保留为迁移源、兼容导入导出与首次迁移失败时的 legacy 可用路径，不与已激活 canonical generation 共同充当查询权威。
  3. JSONL→SQLite 使用 copy-switch 迁移；只有 schema/index、exact parity、内容证明与激活门全部通过后，新 generation 才可发布。
- **后果**：TM 历史、多译文与索引能在单一事务边界中对账；同时保留人可读的 JSONL 配置源与恢复路径。代价是需要显式的迁移、generation 发布和源绑定协议。
- **取代关系**：取代 ADR-002 与 ADR-006 对 canonical runtime 存储/索引的约束；两份旧 ADR 作为 legacy 阶段的历史决策保留。
