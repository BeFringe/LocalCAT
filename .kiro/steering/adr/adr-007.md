# ADR-007：SQLite generation 成为 canonical TM，外部源保留为配置定位与兼容交换面

- **状态**：已采纳
- **日期**：2026-08-16
- **采纳日期**：2026-08-17
- **背景**：ADR-002 与 ADR-006 将 JSONL append-only/LWW 和内存 dict 精确索引定义为当时的 TM 运行时策略。Feature 5 在保留 JSONL 兼容输入、安全迁移与导出能力的同时，已将版本化记录、context/provenance、候选索引和统一查询转移到 SQLite generation。
- **决策**：
  1. 单个已激活资源的 SQLite generation 是 TM 精确、context、fuzzy 查询及本地追加的唯一 canonical runtime authority。
  2. never-activated 资源，以及首次激活取消/失败且从未形成 canonical activation 的资源，继续使用 legacy JSONL exact-only；不同资源可以确定性地同时处于 legacy 与 canonical 状态。
  3. 配置指向的外部源保留为迁移、兼容交换与审计输入。它不与已激活 canonical generation 共同充当查询 authority。
  4. 已经形成 canonical activation 的资源在后续外部源 divergence、迁移失败或新 generation 无法发布时，保留 last-known-good canonical，不得静默回落到 JSONL 查询。
  5. 外部源到 SQLite 使用 copy-switch 迁移；只有 schema/index、exact parity、内容证明与激活门全部通过后，新 generation 才可发布。
- **后果**：TM 历史、多译文与索引能在单一事务边界中对账；同时保留人可读的外部源定位、legacy 首次激活路径与兼容交换面。代价是需要显式的资源状态、迁移、generation 发布和源绑定协议。
- **取代关系**：部分取代 ADR-002 与 ADR-006 对已激活资源 canonical runtime 存储/索引的约束；两份旧 ADR 对 never-activated/cancelled-first legacy exact-only 的约束及历史背景继续保留。
