# ADR-014：设备本地预处理偏好的 workspace 持久化

- **状态**：已采纳
- **日期**：2026-08-20
- **决策 owner**：LocalCAT 项目 owner
- **关联 Spec**：`qt-editor-json-mvp-increment` Requirement 4.12–4.18 / Task 1.2a, 2.2b, 3.3a, 4.4a, 5.5

## 背景

Target 文字预处理需要在重开对话框和应用重启后恢复有序 literal 规则、每条启用状态以及“草稿 / 已确认”筛选。这些值是设备本地交互偏好，不是翻译项目内容，也不是 preview、batch undo 或同步权威。

新增持久数据会改变 `workspace.json` 的兼容读取合同，因此不能仅作为 Qt 实现细节。必须冻结它与项目 JSON、TM/术语资源、执行会话和未来跨设备 package 的边界。

## 决策

1. `WorkspaceStateRepository` 在既有 `workspace.json` schema v1 根对象中拥有可选 `preprocessing` member；缺失该 member 时恢复默认空规则与两个状态全选，不触发 migration 或自动执行。
2. `preprocessing` 是完整偏好图：它只包含按显示顺序的 `{find, replacement, enabled}` 规则以及 exact boolean `include_draft/include_confirmed`；两个状态不得同时为 false。
3. 该 member 不得包含项目路径以外的项目内容、source/target/speaker、project/session/revision、preview、search issuance、batch undo 或应用结果。它不进入项目包、TM/术语资源包或跨设备同步权威。
4. 读取时对整个 preference graph 严格验证；任一字段缺失、错型或违反不变式时，只将该组退回安全默认，不丢失其他合法 workspace 偏好。
5. 保存继续使用同目录临时文件、file fsync 和 `os.replace`。任一写入失败保留上一份成功文件和内存 last-known-good，不改变当前项目、dirty、revision、search 或 undo。
6. Qt 只能通过 `EditorController` 的 defensive contract 读写该偏好；保存是独立显式动作，不得自动 preview 或 apply。

## 长期约束

- 预处理偏好始终是 device-local presentation/application preference，不可提升为翻译项目、段落或资源 authority。
- 未来若要跨设备传输规则，必须由独立资源可移植/同步规格定义版本、导入和冲突语义；不得直接复制 live `workspace.json`。
- schema v1 的未知根 member 不因本决策获得普遍写入授权；新持久图仍需逐项经过格式/兼容门。

## 后果与权衡

用户可稳定恢复规则和状态筛选，无需把它们混入项目 JSON。代价是 `workspace.json` 多一个受契约的可选 member，读写、旧文件兼容与故障原子性必须持续由专项测试保护。

## 备选方案

- **写入项目 JSON**：拒绝。这会把设备偏好变成项目内容，并污染未来 package/sync authority。
- **另建无版本规则文件**：拒绝。它会创建第二个本地偏好事务边界，且缺失既有 workspace 恢复语义。
- **只保留对话框内存状态**：拒绝。不能满足重开/重启恢复的用户要求。
- **保存后立即运行**：拒绝。保存与对项目的变更必须是两个显式动作。
