# ADR-030：显式目录选择、单文档项目包与中立格式导出

- **状态**：已采纳
- **日期**：2026-10-05
- **决策 owner**：LocalCAT 项目 owner
- **关联 Spec**：`multi-document-project-workspace` Requirement 13；`rpy-project-codec`；Parser、平台和 Qt 的对应接缝

## 背景

用户已批准 RPY、目录选择和同步 R/D/T 并要求实施。嵌套 TL 需要显式选择根目录、递归预览后勾选文件；单个 TL 同样需要用 ProjectPackage 保存。既有 ADR-018 的首批显式文件列表与 RPY 在 Sync 后的顺序不足以覆盖本轮范围，Parser prepared 发布和平台目录观察/创建需要明确授权边界。

## 决策

1. Project 负责用户触发的有界目录 metadata 发现、候选树和显式勾选；平台提供 retained-root/no-follow 的只读观察。未勾选内容不读取、不 parse；不启用后台自动发现或自动加入项目。source_ref 始终相对于最初选择根，目录树导航不改变 manifest 顺序或 identity。
2. 新增非 legacy `single_file/explicit-single-file-v1`，恰含一个 Document；多个仍使用 `directory/explicit-selected-files-v1`。持久化沿用 ADR-019 的严格 ProjectPackage，不新增 carrier 或重复 target 权威。现有 legacy JSON 单文件行为保留。
3. Parser 提供可选 round-trip prepare 与 prepared publish 接缝：codec 负责 grammar、私有映射、文字保护和输出内容；Parser 复证 exact live codec、源/输出指纹、一次性准备结果与目标绑定。Application 协调，平台执行原子发布，Qt 仅消费中立投影。配置只选择产品内可信 provider，包不能授权执行。
4. 平台提供导出根内受控子目录准备/创建/绑定。预览绑定已有祖先与缺失目录/目标的 absent 条件；确认后逐组件创建，竞争或身份替换即 stale。目录观察、目录创建和 retirement authority 不互相冒充。
5. 用户显式批量导出 TL 时，先准备全部候选，再按原相对目录逐文件发布；逐文件返回成功、失败、不确定或未执行，不承诺跨文件原子性，不虚构已建空目录/已发布文件回滚。此格式导出不更新 ProjectPackage baseline，不设 codec journal/LKG；ProjectPackage 保存及其他 owner 的恢复协议保持不变。
6. 产品顺序为目录/单文档接缝与 RPY 手工包闭环先行，随后 Sync。RPY codec 在 LocalCAT 内自包含，支持范围由独立 grammar/golden 明确；无外部前项目运行或测试依赖。

## 长期约束

- Project/Document/Segment identity、overlay 和包事务仍由 Project 唯一拥有；opaque private member 不成为第二份编辑状态。
- 本决策不开放任意游戏执行、完整 Ren'Py AST、workbook、多 Sheet 或其他格式 writer。
- 新目录能力通过平台 owner 的中立端口，业务模块不得自行散落 POSIX/Win32 原语。
- 批量导出与项目持久化分开报告，prepared 结果不授权任意 bytes 或任意路径写入。

## 后果与权衡

单 TL 与嵌套章节使用同一持久模型，代价是新增单文件 profile 验证和有界目录能力。批量格式导出明确允许部分完成；需要整项目 durable 保存时仍保存 ProjectPackage。单文件和目录能力均须进行真实 backend、包冷重开和 UI 验证。

## 备选方案

- 外部脚本/JSON 与 sidecar 文件对：不采用，不能满足自包含与单包持久化。
- 根目录自动全部导入：不采用，用户必须预览勾选。
- RPY 批量导出另建事务日志：不采用，沿用 ADR-026 的无状态格式发布边界，逐文件诚实报告。

## 取代关系

- **部分取代** ADR-018 决策 9 的首批不枚举限制，仅新增用户触发 metadata 预览；显式确认和 root 安全约束保留。
- **部分取代** ADR-018 决策 13 的 RPY/Sync 顺序，改为 RPY 手工包先行。
- **澄清并局部取代** ADR-018 决策 7 的目录日志前置，仅针对本决策的显式 RPY 格式批量导出采用无 codec journal 的逐文件结果；既有项目保存、源调和和其他 directory/workbook 事务不变。
- **接续** ADR-015/019/020/025/026；不改写其余格式、authority、保存恢复或平台约束。
- **被取代于**：无。
