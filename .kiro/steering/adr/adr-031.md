# ADR-031：可选协议适配与手动包同步状态

- **状态**：已采纳
- **日期**：2026-10-05
- **决策 owner**：LocalCAT 项目 owner
- **关联 Spec**：`cross-device-sync-plugin`；ProjectPackage、ResourcePackage、平台秘密后端与 Qt

## 背景

用户需要使用自己的 S3-compatible 或 WebDAV 服务跨设备继续工作。R2 与 InfiniCLOUD 是首批验收服务，不是产品固定 provider。完整包传输、远端并发版本与设备同步状态需要独立合同，不能复用项目/资源 authority 或把普通文件镜像视为事务同步。

## 决策

1. 同步为显式 opt-in 的 Application 组合；禁用不构造网络 client、不请求秘密、不启动 worker。本地编辑保存不依赖网络。首版只有用户发起的 push/pull/two-way，无后台定时任务、账号体系或内容加密。
2. 两种协议适配器为 S3-compatible 与 WebDAV。endpoint、region、寻址方式、bucket/prefix、完整 DAV base URL 与凭据来源由连接配置提供；厂商仅作可编辑预设/验收实例，不按域名或固定变量名授予资格。条件写能力按配置连接验证，未知时只读，禁止无条件覆盖回退。
3. Sync 只消费已完成且由 owner 验证的整包受限 artifact。Project 新增独立 retained 整包出口；Resource 复用自己的 artifact 合同。provider 不解析包，不获得本地路径、manifest、member、live SQLite/journal 或设备资格。
4. `sync-transport-v1` 采用 immutable `objects/<sha256>.bin` 与条件提交 `heads/<item_uuid>.json`。完整 object 确认后以 absent/强版本 CAS 提交 head；删除为保留旧包的 tombstone，首版不做远端 GC。ETag 只是条件 token，不能作为内容摘要。
5. `sync-state-v1` 是设备本地、按 connection 加锁的独立持久状态，保存显式绑定、成对 base、pending intent 和必要恢复引用。base 对应 owner 内容 fingerprint 与远端 artifact/version；上传确认及下载 owner 提交、内容复证均完成后才能推进。不得以包外壳字节、mtime 或来源不明的 receipt 推进。
6. 无共同基线、列举不完整、路径失联或未选资源不推断删除。冲突保留双方，经新预览明确决策。下载先完整校验，再交对应 owner preview/apply；远端 ID 不选择本地目标或授权覆盖。导入后内容不同显示待对齐，不假装共同基线。
7. 未知上传结果按 operation ID/head 复证；owner apply 后结果未知则停止自动重放，消费已有 owner recovery 或通过显式新观测建立新计划，不补造历史 receipt。跨包操作不宣称全局原子性。
8. 秘密使用限定系统 backend、当前会话或显式环境变量引用，默认遮蔽、可点击显示，关闭后恢复遮蔽。值不进入 Git、包、配置普通字段、错误或日志。HTTPS 验证证书；不启用默认凭据链，不向未批准目标转发认证信息。
9. 可选网络/秘密依赖由可信 composition 管理，采用 botocore、keyring 系统 backend 和 defusedxml；固定兼容版本及发行闭包。S3 用 R2 首批实测，WebDAV 用 InfiniCLOUD 首批实测，fake server 不替代真实隔离前缀验收。

## 长期约束

Project 与 Resource 继续拥有独立 schema、identity、导入事务、receipt 和恢复。Sync 不解释 codec 私有数据，不共享翻译语义 authority，不搬运 Chunk 权限或 Fuzzy 资格。连接配置变化撤销旧计划/能力，不把另一远端基线用于新连接。

## 后果与权衡

完整包与条件 head 保留清晰 owner 边界并保护并发更新，代价是独立同步状态及历史对象空间。只读降级和待对齐会要求显式用户决策；它们优先于猜测成功或静默覆盖。实际云端验收仅操作明确批准的合成测试前缀。

## 备选方案

工作目录镜像、mtime/LWW、通用 Package authority、动态安装远端插件、自动语义合并均不采用。

## 取代关系

- **接续** ADR-018/019 的完整包同步边界，不取代项目/资源权威。
- **扩展** 本地优先原则：仅批准用户显式启用的受限网络传输；禁用行为与本地工作流不变。
- **被取代于**：无。
